# Sleightbook MVP1 — Part 3: Web App & End-to-End Tests

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apps/web` — the Trick Detail page for Ambitious Card with the interactive SVG visualizer (play/pause/next/prev/replay/speed/phase jump, Spectator ⇄ Secret), synchronized breakdown, favorites, phase & trick notes, English/Indonesian UI — and cover the MVP1 flow with Playwright.

**Architecture:** Hybrid conventions (spec D1). Layers: `api/` (local data layer persisted in localStorage while Part 2 is postponed; same async signatures the Hono client will have) → `business/` (`do*` orchestration, toasts, store updates) → `store/` (Zustand) → `components/` & `contents/` (UI only). The visualizer renders `layout(project(stateAt(timeline, frame), view))` from `@sleightbook/engine` with Motion; the `usePlayer` store owns all playback semantics and is unit-tested without a DOM.

**Tech Stack:** React 19, Vite, Tailwind CSS v4, Motion (`motion/react`), React Router v7, Zustand, react-i18next, sonner, Zod 4, Playwright.

**Spec:** [`docs/superpowers/specs/2026-09-26-sleightbook-mvp1-design.md`](../specs/2026-09-26-sleightbook-mvp1-design.md) (§4.4, §4.5, §6, §7)

**Series:** [Part 1](2026-09-26-mvp1-part1-foundation-engine.md) → [Part 2](2026-09-26-mvp1-part2-api.md) → Part 3 (this)

## Global Constraints

- **NO GIT COMMITS** (spec D8).
- Part 1 is complete. **Part 2 (API + Postgres) is postponed by the user (2026-09-26).** The web app uses a local data layer (`src/api/localDb.ts`, persisted in localStorage, seeded from `AMBITIOUS_CARD`) behind the `api/*API.ts` functions; nothing in `business/`, `store/`, `components/` or `contents/` may know the data is local.
- Conventions: named exports; props `interface XxxProps` above the component; component order = hooks → handlers (`handle*`) → JSX → internal sub-components at the bottom of the file; business functions `do*`; components never import from `api/`; stores read in business via `.getState()`; types in `src/types/*.types.ts` (domain types come from `@sleightbook/shared`); `import type` for types; no `any`; no barrel files.
- Styling: Tailwind v4 utilities using the `@theme` tokens in `src/index.css` only — no hex colors in components.
- Every `<button>` has `type="button"` or `type="submit"`. Icon-only buttons have `aria-label`. Toggles use `aria-pressed`. Minimum text size `text-xs` (12px).
- All UI strings go through `t()`; `en.json` and `id.json` must have identical key sets (enforced by a test).
- No dead UI: nothing is rendered that does not work (no tabs, AI card, variations, search, settings).
- Playback semantics (spec §4.4): navigation unit = phase; `next` animates the following phase; `prev` jumps without animation and pauses; `play` auto-advances with `PHASE_GAP_MS = 600` between phases and stops at the end; `play` at the end = `replay`; speed ∈ {0.5, 0.75, 1, 1.25, 1.5, 2} and applies immediately; reduced motion → duration 0.
- Default view is `secret`.

import type { IFormattedCard } from "../types/card.types";

const SUITS: Record<string, { symbol: string; isRed: boolean }> = {
  S: { symbol: "♠", isRed: false },
  H: { symbol: "♥", isRed: true },
  D: { symbol: "♦", isRed: true },
  C: { symbol: "♣", isRed: false },
};

export const formatCardLabel = (label: string): IFormattedCard => {
  const suit = label.length >= 2 ? SUITS[label.slice(-1)] : undefined;
  if (!suit) return { rank: label, suit: "", isRed: false, text: label };
  const rank = label.slice(0, -1);
  return { rank, suit: suit.symbol, isRed: suit.isRed, text: `${rank}${suit.symbol}` };
};

export const formatSpeed = (speed: number): string => `${speed.toFixed(2).replace(/0$/, "")}×`;
```

export const upsertById = <T extends { id: string }>(list: readonly T[], item: T): T[] =>
  list.some((entry) => entry.id === item.id)
    ? list.map((entry) => (entry.id === item.id ? item : entry))
    : [...list, item];

export const removeById = <T extends { id: string }>(list: readonly T[], id: string): T[] =>
  list.filter((entry) => entry.id !== id);
```

```ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";

import type { TLanguage } from "../types/i18n.types";
import en from "./locales/en.json";
import id from "./locales/id.json";

export const LANGUAGES: readonly TLanguage[] = ["en", "id"];
export const LANGUAGE_STORAGE_KEY = "sleightbook.language";

const readStoredLanguage = (): TLanguage => {
  try {
    return window.localStorage.getItem(LANGUAGE_STORAGE_KEY) === "id" ? "id" : "en";
  } catch {
    return "en";
  }
};

const initialLanguage = readStoredLanguage();

void i18n.use(initReactI18next).init({
  resources: { en: { translation: en }, id: { translation: id } },
  lng: initialLanguage,
  fallbackLng: "en",
  interpolation: { escapeValue: false },
});
document.documentElement.lang = initialLanguage;

export const changeLanguage = (language: TLanguage): void => {
  void i18n.changeLanguage(language);
  document.documentElement.lang = language;
  try {
    window.localStorage.setItem(LANGUAGE_STORAGE_KEY, language);
  } catch {
    // Storage can be unavailable (private mode); the choice then lasts for this session only.
  }
};

export { i18n };
```

export interface IStorageLike {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
}

export const createMemoryStorage = (): IStorageLike => {
  const data = new Map<string, string>();
  return {
    getItem: (key) => data.get(key) ?? null,
    setItem: (key, value) => {
      data.set(key, value);
    },
  };
};

// localStorage can be missing (tests) or throw (private mode); fall back to memory.
export const getBrowserStorage = (): IStorageLike => {
  try {
    if (typeof window !== "undefined" && window.localStorage) {
      const probeKey = "sleightbook.probe";
      window.localStorage.setItem(probeKey, probeKey);
      window.localStorage.removeItem(probeKey);
      return window.localStorage;
    }
  } catch {
    // Fall through to in-memory storage.
  }
  return createMemoryStorage();
};

import type { ITrickFixture } from "@sleightbook/shared/fixtures/ambitiousCard";
import type { IPhase, IRoutineDetail, ITechnique } from "@sleightbook/shared/schemas/routine";
import type { IItem, ITrickDetail } from "@sleightbook/shared/schemas/trick";

import type { ILocalDatabase } from "../types/localDb.types";

export const buildSeedDatabase = (fixture: ITrickFixture, newId: () => string, now: string): ILocalDatabase => {
  const trickId = newId();
  const routineId = newId();

  const techniqueByName = new Map<string, ITechnique>(
    fixture.techniques.map((technique) => [technique.name, { id: newId(), ...technique }]),
  );
  const items: IItem[] = fixture.items.map((item) => ({ id: newId(), ...item }));

  const phases: IPhase[] = fixture.phases.map((phase, position) => ({
    id: newId(),
    position,
    name: phase.name,
    summary: phase.summary,
    explanation: phase.explanation,
    spectatorText: phase.spectatorText,
    actions: phase.actions.map((record, actionPosition) => ({
      id: newId(),
      position: actionPosition,
      durationMs: record.durationMs,
      action: record.action,
    })),
    techniques: phase.techniques
      .map((name) => {
        const technique = techniqueByName.get(name);
        if (!technique) throw new Error(`Unknown technique in fixture: ${name}`);
        return technique;
      })
      .sort((a, b) => a.name.localeCompare(b.name)),
    notes: [],
  }));

  const trick: ITrickDetail = {
    id: trickId,
    ...fixture.trick,
    isFavorite: false,
    items,
    routines: [{ id: routineId, name: fixture.routine.name, isDefault: true, position: 0 }],
    defaultRoutineId: routineId,
    notes: [
      {
        id: newId(),
        body: fixture.trickNote,
        trickId,
        routineId: null,
        phaseId: null,
        techniqueId: null,
        itemId: null,
        createdAt: now,
        updatedAt: now,
      },
    ],
  };

  const routine: IRoutineDetail = {
    id: routineId,
    trickId,
    name: fixture.routine.name,
    description: fixture.routine.description,
    tips: [...fixture.routine.tips],
    phases,
  };

  return { version: 1, tricks: [trick], routines: [routine] };

`apps/web/src/api/localDb.ts`:

```ts
import { z } from "zod";

import { AMBITIOUS_CARD } from "@sleightbook/shared/fixtures/ambitiousCard";
import { CreateNoteSchema, type ICreateNoteInput, type INote, UpdateNoteSchema } from "@sleightbook/shared/schemas/note";
import { type IRoutineDetail, RoutineDetailSchema } from "@sleightbook/shared/schemas/routine";
import { type ITrickDetail, type ITrickSummary, TrickDetailSchema } from "@sleightbook/shared/schemas/trick";

import type { ILocalDatabase } from "../types/localDb.types";
import { ApiError } from "./apiError";
import { buildSeedDatabase } from "./seedData";
import { getBrowserStorage, type IStorageLike } from "./storage";

export const DB_STORAGE_KEY = "sleightbook.db.v1";

const LocalDatabaseSchema = z.object({
  version: z.literal(1),
  tricks: z.array(TrickDetailSchema),
  routines: z.array(RoutineDetailSchema),
});

interface ILocalDbOptions {
  storage: IStorageLike;
  newId: () => string;
  now: () => string;
}

const notFound = (entity: string): ApiError => new ApiError(404, "NOT_FOUND", `${entity} not found`);

const validationError = (error: z.ZodError): ApiError =>
  new ApiError(400, "VALIDATION", error.issues.map((issue) => issue.message).join("; "));

export const createLocalDb = ({ storage, newId, now }: ILocalDbOptions) => {
  const save = (database: ILocalDatabase): void => storage.setItem(DB_STORAGE_KEY, JSON.stringify(database));

  const load = (): ILocalDatabase => {
    const raw = storage.getItem(DB_STORAGE_KEY);
    if (raw) {
      try {
        const parsed = LocalDatabaseSchema.safeParse(JSON.parse(raw));
        if (parsed.success) return parsed.data;
      } catch {
        // Corrupt JSON: reseed below.
      }
    }
    const seeded = buildSeedDatabase(AMBITIOUS_CARD, newId, now());
    save(seeded);
    return seeded;
  };

  const findTrick = (database: ILocalDatabase, trickId: string): ITrickDetail => {
    const trick = database.tricks.find((candidate) => candidate.id === trickId);
    if (!trick) throw notFound("Trick");
    return trick;
  };

  const findRoutine = (database: ILocalDatabase, routineId: string): IRoutineDetail => {
    const routine = database.routines.find((candidate) => candidate.id === routineId);
    if (!routine) throw notFound("Routine");
    return routine;
  };

  const findNoteList = (database: ILocalDatabase, noteId: string): INote[] => {
    const trickList = database.tricks.find((trick) => trick.notes.some((note) => note.id === noteId))?.notes;
    if (trickList) return trickList;
    for (const routine of database.routines) {
      const phase = routine.phases.find((candidate) => candidate.notes.some((note) => note.id === noteId));
      if (phase) return phase.notes;
    }
    throw notFound("Note");
  };

  return {
    listTricks: (): ITrickSummary[] =>
      load()
        .tricks.map(({ id, name, slug, category, difficulty, isFavorite }) => ({
          id,
          name,
          slug,
          category,
          difficulty,
          isFavorite,
        }))
        .sort((a, b) => a.name.localeCompare(b.name)),

    getTrick: (trickId: string): ITrickDetail => structuredClone(findTrick(load(), trickId)),

    setFavorite: (trickId: string, isFavorite: boolean): ITrickDetail => {
      const database = load();
      const trick = findTrick(database, trickId);
      trick.isFavorite = isFavorite;
      save(database);
      return structuredClone(trick);
    },

    getRoutine: (routineId: string): IRoutineDetail => structuredClone(findRoutine(load(), routineId)),

    createNote: (input: ICreateNoteInput): INote => {
      const parsed = CreateNoteSchema.safeParse(input);
      if (!parsed.success) throw validationError(parsed.error);
      const { body, trickId, phaseId } = parsed.data;
      if (!trickId && !phaseId) {
        throw new ApiError(400, "NOT_SUPPORTED", "Local mode supports trick and phase notes only");
      }

      const database = load();
      const timestamp = now();
      const note: INote = {
        id: newId(),
        body,
        trickId: trickId ?? null,
        routineId: null,
        phaseId: phaseId ?? null,
        techniqueId: null,
        itemId: null,
        createdAt: timestamp,
        updatedAt: timestamp,
      };

      if (trickId) {
        findTrick(database, trickId).notes.push(note);
      } else {
        const phase = database.routines
          .flatMap((routine) => routine.phases)
          .find((candidate) => candidate.id === phaseId);
        if (!phase) throw notFound("Note target");
        phase.notes.push(note);
      }
      save(database);
      return structuredClone(note);
    },

    updateNote: (noteId: string, body: string): INote => {
      const parsed = UpdateNoteSchema.safeParse({ body });
      if (!parsed.success) throw validationError(parsed.error);
      const database = load();
      const notes = findNoteList(database, noteId);
      const index = notes.findIndex((note) => note.id === noteId);
      const updated: INote = { ...notes[index], body: parsed.data.body, updatedAt: now() };
      notes[index] = updated;
      save(database);
      return structuredClone(updated);
    },

    deleteNote: (noteId: string): void => {
      const database = load();
      const notes = findNoteList(database, noteId);
      notes.splice(
        notes.findIndex((note) => note.id === noteId),
        1,
      );
      save(database);
    },
  };
};

export type TLocalDb = ReturnType<typeof createLocalDb>;

// App instance. Replaced by the Hono client once the API (Part 2) exists.
export const localDb = createLocalDb({
  storage: getBrowserStorage(),
  newId: () => crypto.randomUUID(),
  now: () => new Date().toISOString(),
});
```

```ts
import { create } from "zustand";

import type { ITimeline, TView } from "@sleightbook/engine/types";

import { JUMP_SETTLE_MS, PHASE_GAP_MS } from "../constants/playback";
import type { TSpeed } from "../types/player.types";

export interface IPlayerState {
  timeline: ITimeline | null;
  phaseIndex: number;
  frameIndex: number;
  targetFrame: number;
  isJump: boolean;
  isPlaying: boolean;
  speed: TSpeed;
  view: TView;
  showExplanations: boolean;
}

interface IPlayerStore extends IPlayerState {
  load: (timeline: ITimeline) => void;
  goToPhase: (index: number) => void;
  next: () => void;
  prev: () => void;
  play: () => void;
  pause: () => void;
  togglePlay: () => void;
  replay: () => void;
  tick: () => void;
  setSpeed: (speed: TSpeed) => void;
  setView: (view: TView) => void;
  toggleView: () => void;
  setShowExplanations: (showExplanations: boolean) => void;
}

export type TTickInput = Pick<
  IPlayerState,
  "timeline" | "phaseIndex" | "frameIndex" | "targetFrame" | "isPlaying" | "speed"
>;

export const INITIAL_PLAYER_STATE: IPlayerState = {
  timeline: null,
  phaseIndex: 0,
  frameIndex: -1,
  targetFrame: -1,
  isJump: true,
  isPlaying: false,
  speed: 1,
  view: "secret",
  showExplanations: true,
};

const lastPhaseIndex = (timeline: ITimeline): number => timeline.phaseEnds.length - 1;

const phaseStartFrame = (timeline: ITimeline, phaseIndex: number): number =>
  phaseIndex === 0 ? -1 : timeline.phaseEnds[phaseIndex - 1];

export const usePlayerStore = create<IPlayerStore>((set, get) => ({
  ...INITIAL_PLAYER_STATE,
  load: (timeline) => {
    const firstEnd = timeline.phaseEnds[0];
    set({ timeline, phaseIndex: 0, frameIndex: firstEnd, targetFrame: firstEnd, isJump: true, isPlaying: false });
  },
  goToPhase: (index) => {
    const { timeline } = get();
    if (!timeline) return;
    const phaseIndex = Math.min(Math.max(index, 0), lastPhaseIndex(timeline));
    set({
      phaseIndex,
      frameIndex: phaseStartFrame(timeline, phaseIndex),
      targetFrame: timeline.phaseEnds[phaseIndex],
      isJump: true,
    });
  },
  next: () => {
    const { timeline, phaseIndex, goToPhase } = get();
    if (!timeline || phaseIndex >= lastPhaseIndex(timeline)) return;
    goToPhase(phaseIndex + 1);
  },
  prev: () => {
    const { timeline, phaseIndex } = get();
    if (!timeline) return;
    const target = Math.max(phaseIndex - 1, 0);
    const frame = timeline.phaseEnds[target];
    set({ phaseIndex: target, frameIndex: frame, targetFrame: frame, isJump: true, isPlaying: false });
  },
  play: () => {
    const { timeline, phaseIndex, frameIndex, replay } = get();
    if (!timeline) return;
    const isAtEnd =
      phaseIndex === lastPhaseIndex(timeline) && frameIndex === timeline.phaseEnds[phaseIndex];
    if (isAtEnd) {
      replay();
      return;
    }
    set({ isPlaying: true });
  },
  pause: () => set({ isPlaying: false }),
  togglePlay: () => {
    const { isPlaying, play, pause } = get();
    if (isPlaying) pause();
    else play();
  },
  replay: () => {
    const { timeline, goToPhase } = get();
    if (!timeline) return;
    goToPhase(0);
    set({ isPlaying: true });
  },
  tick: () => {
    const { timeline, frameIndex, targetFrame, isPlaying, phaseIndex, goToPhase } = get();
    if (!timeline) return;
    if (frameIndex < targetFrame) {
      set({ frameIndex: frameIndex + 1, isJump: false });
      return;
    }
    if (!isPlaying) return;
    if (phaseIndex < lastPhaseIndex(timeline)) {
      goToPhase(phaseIndex + 1);
      return;
    }
    set({ isPlaying: false });
  },
  setSpeed: (speed) => set({ speed }),
  setView: (view) => set({ view }),
  toggleView: () => set(({ view }) => ({ view: view === "secret" ? "spectator" : "secret" })),
  setShowExplanations: (showExplanations) => set({ showExplanations }),
}));

export const getTickDelay = (state: TTickInput, reducedMotion: boolean): number | null => {
  const { timeline, phaseIndex, frameIndex, targetFrame, isPlaying, speed } = state;
  if (!timeline) return null;
  const isAnimating = frameIndex < targetFrame;
  if (!isAnimating && !isPlaying) return null;
  if (reducedMotion) return isAnimating ? 0 : PHASE_GAP_MS;

  const isPhaseStart = frameIndex < 0 || frameIndex === phaseStartFrame(timeline, phaseIndex);
  const currentDuration = isPhaseStart ? JUMP_SETTLE_MS : timeline.frames[frameIndex].durationMs;
  return (isAnimating ? currentDuration : currentDuration + PHASE_GAP_MS) / speed;
};
```

import { useEffect } from "react";

import { useReducedMotion } from "motion/react";

import { getTickDelay, usePlayerStore } from "../store/usePlayer";

export const useTimelinePlayback = () => {
  const { timeline, phaseIndex, frameIndex, targetFrame, isPlaying, speed, tick } = usePlayerStore();
  const reducedMotion = useReducedMotion() ?? false;

  useEffect(() => {
    const delay = getTickDelay({ timeline, phaseIndex, frameIndex, targetFrame, isPlaying, speed }, reducedMotion);
    if (delay === null) return;
    const timer = window.setTimeout(tick, delay);
    return () => window.clearTimeout(timer);
  }, [timeline, phaseIndex, frameIndex, targetFrame, isPlaying, speed, reducedMotion, tick]);

  useEffect(() => () => usePlayerStore.getState().pause(), []);
};

  perceivedText: string | null;
}) => {
  if (node.kind === "deckBlock") return <DeckBlock patternId={patternId} />;
  const badgeY = node.zone === "buried" ? CARD_HEIGHT + 14 : -8;
  return (
    <>
      {node.face === "up" ? (
        <CardFace label={node.label} highlight={node.highlight} />
      ) : (
        <CardBack patternId={patternId} highlight={node.highlight} />
      )}
      {perceivedText && (
        <text x={CARD_WIDTH / 2} y={badgeY} textAnchor="middle" className="fill-gold-2 text-[9px] font-semibold">
          {perceivedText}
        </text>
      )}
    </>
  );
};

const CardFace = ({ label, highlight }: { label: string; highlight: THighlight }) => {
  const card = formatCardLabel(label);
  const inkClass = card.isRed ? "fill-card-red" : "fill-card-ink";
  return (
    <>
      <rect
        width={CARD_WIDTH}
        height={CARD_HEIGHT}
        rx={6}
        className={`fill-card-face ${strokeClass(highlight, "stroke-subtle")}`}
        strokeWidth={strokeWidth(highlight)}
        strokeDasharray={dashArray(highlight)}
      />
      <text x={7} y={16} className={`${inkClass} text-[11px] font-bold`}>
        {card.text}
      </text>
      <text x={CARD_WIDTH / 2} y={CARD_HEIGHT / 2 + 11} textAnchor="middle" className={`${inkClass} text-[30px] font-bold`}>
        {card.suit || card.rank}
      </text>
    </>
  );
};

const CardBack = ({ patternId, highlight }: { patternId: string; highlight: THighlight }) => (
  <>
    <rect
      width={CARD_WIDTH}
      height={CARD_HEIGHT}

  const [editingId, setEditingId] = useState<string | null>(null);
  const [editingBody, setEditingBody] = useState("");
  const [isSaving, setIsSaving] = useState(false);

  const handleDraftChange = (event: ChangeEvent<HTMLTextAreaElement>) => setDraft(event.target.value);
  const handleEditingBodyChange = (event: ChangeEvent<HTMLTextAreaElement>) => setEditingBody(event.target.value);
  const handleEditStart = (note: INote) => {
    setEditingId(note.id);
    setEditingBody(note.body);
  };
  const handleEditCancel = () => setEditingId(null);
  const handleAddSubmit = async (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const body = draft.trim();
    if (!body) return;
    setIsSaving(true);
    const isSaved = await doCreateNote({ body, ...target });
    setIsSaving(false);
    if (isSaved) setDraft("");
  };
  const handleEditSubmit = async (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const body = editingBody.trim();
    if (!editingId || !body) return;
    setIsSaving(true);
    const isSaved = await doUpdateNote(editingId, body);
    setIsSaving(false);
    if (isSaved) setEditingId(null);
  };
  const handleDelete = (noteId: string) => {
    void doDeleteNote(noteId);
  };

  return (
    <Panel title={title}>
      {notes.length === 0 && <p className="text-sm text-muted">{t("notes.empty")}</p>}
      <ul className="space-y-2">
        {notes.map((note) => (
          <li key={note.id} className="rounded-md border border-gold-dim/50 bg-panel-2 p-2.5 text-sm">
            {editingId === note.id ? (
              <form onSubmit={handleEditSubmit} className="space-y-2">
                <textarea
                  aria-label={t("notes.editLabel")}
                  value={editingBody}
                  onChange={handleEditingBodyChange}
                  rows={3}
                  className="field"
                />
                <div className="flex gap-2">
                  <button type="submit" disabled={isSaving} className="btn-primary">
                    {t("notes.save")}
                  </button>
                  <button type="button" onClick={handleEditCancel} className="btn-secondary">
                    {t("notes.cancel")}
                  </button>
                </div>
              </form>
            ) : (
              <>
                <p className="whitespace-pre-wrap text-fg">{note.body}</p>
                <div className="mt-2 flex gap-3 text-xs">
                  <button type="button" onClick={() => handleEditStart(note)} className="text-muted hover:text-gold-2">
                    {t("notes.edit")}
                  </button>
                  <button type="button" onClick={() => handleDelete(note.id)} className="text-muted hover:text-danger">
                    {t("notes.delete")}
                  </button>
                </div>
              </>
            )}
          </li>
        ))}
      </ul>
      <form onSubmit={handleAddSubmit} className="mt-3 space-y-2">
        <textarea
          aria-label={t("notes.placeholder")}
          placeholder={t("notes.placeholder")}
          value={draft}
          onChange={handleDraftChange}
          rows={2}
          className="field"
        />
        <button type="submit" disabled={isSaving || draft.trim() === ""} className="btn-secondary">
          {t("notes.add")}
        </button>
      </form>
    </Panel>
  );
};
